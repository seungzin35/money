# 매일 글 1개 자동 작성 규칙 (ZIN 머니)

예약 작업이 이 문서를 읽고 글 1개를 써서 기본 브랜치(`main`)에 올립니다.
매일 오전 9시 5분(한국 시간)에 `Deploy to GitHub Pages` 워크플로가 자동으로 배포합니다.

## 주제 고르기

- 사회초년생이 구글에서 꾸준히 검색하는 돈 관리 **기초 개념과 절차**만 고릅니다. (예: "DSR 뜻", "실비 청구 방법")
- 카테고리는 `src/navigation.ts` 중 하나: 신용·카드, 저축·투자 기초, 대출, 보험, 세금·월급. 최근 글과 겹치지 않게 돌아가며 고릅니다.
- `Korea Life Guide` 카테고리는 외국인 대상 **영어 글 전용**입니다. 매일 자동 글에서는 고르지 않고, 사용자가 요청할 때만 영어로 씁니다.
- `src/data/post/` 에 이미 있는 글과 주제가 겹치면 안 됩니다.
- 쓰지 않는 것: 특정 상품·카드·보험·종목 추천, 지원금·정책 뉴스, 금리 전망.

## 정보 검증 (필수)

- 숫자·제도·절차는 공식 기관 자료에서 직접 확인합니다: 금융감독원(파인, 금융상품 한눈에), 금융위원회, 국세청·홈택스, 국민건강보험공단, 국민연금공단, 예금보험공사, 정부 포털(복지로, 정부24).
- 공식 자료로 확인되지 않는 내용은 쓰지 않습니다.
- 계산 예시는 숫자를 직접 다시 계산해 검산합니다.
- 금리·세율·한도처럼 바뀌는 숫자에는 시행일이나 기준일을 본문에 적고, frontmatter `asOf` 에 확인한 달을 넣습니다.
- 글 끝에 `_참고: 출처 문서 이름_` 을 적고, 본문에 공식 페이지 링크를 답니다.

## 글 형식

- 파일: `src/data/post/<영문-슬러그>.md`
- frontmatter: `publishDate` (그날 09:00 +09:00), `title`, `excerpt`, `category`, `coverIcon`, `coverTitle`, `coverSub`, `asOf` (예: `2026-11`), `tags`
- `coverIcon`: 주제에 맞는 Tabler 아이콘. `node_modules/@iconify-json/tabler/icons.json` 에 있어야 합니다.
- `coverTitle`: 표지 제목. 한 줄에 7자 안팎, `|` 로 줄 나눔(2~3줄), 강조할 단어는 `[대괄호]` (초록색).
- `coverSub`: 표지 아래 짧은 문구, 12자 안팎.
- 구성: 도입 → 한눈에 보는 표 → 개념 설명 → 계산 예시나 절차(번호) → 주의할 점 → 정리.
- 쉬운 한국어, 어려운 용어는 처음 나올 때 풀어 씁니다.
- 다른 글 링크는 반드시 슬래시(/)로 시작: `[제목](/deposit-vs-savings)`

## 올리기 전 확인

2. `npm run check`
3. `npx astro build` 성공
4. 커밋 후 `git pull --rebase` 하고 푸시
