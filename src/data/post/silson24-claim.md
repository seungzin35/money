실손보험(실비보험)에 가입했는데 병원비를 청구하지 않고 넘어간 적이 있다면, 대부분은 "서류 떼러 가기 귀찮아서"일 거예요. 2024년 10월부터는 이 과정이 많이 바뀌었습니다. 병원이 보험회사로 서류를 **전자로 바로 보내 주는** 실손보험 청구 전산화가 시작됐기 때문입니다.

이 글에서는 청구 전산화가 무엇인지, 어떤 병원에서 쓸 수 있는지, **실손24** 앱으로 청구하는 순서를 금융위원회 발표 자료를 기준으로 정리했습니다.

## 실손보험 청구 전산화 한눈에

| 항목              | 내용                                                              |
| ----------------- | ----------------------------------------------------------------- |
| 하는 일           | 병원이 청구에 필요한 서류를 보험회사로 **전자 전송**              |
| 쓰는 곳           | **실손24** 앱 또는 웹페이지 (보험개발원이 전송대행기관으로 운영)  |
| 1단계 시작        | 2024년 10월 25일, 병원급 의료기관(병상 30개 이상 등)과 보건소     |
| 2단계 시작        | 2025년 10월 25일, 의원과 약국                                     |
| 종이 없이 가는 것 | 진료비 계산서·영수증, 진료비 세부산정내역서, 처방전               |
| 전송 가능한 진료  | 2024년 10월 25일 이후에 생긴 진료비 내역부터                      |
| 주의              | 모든 병원이 참여한 것은 아님. 내가 간 병원이 참여했는지 먼저 확인 |

위 내용은 금융위원회 보도자료 [「’24.10.25일부터 ‘창구 방문 없는’, ‘복잡한 서류 없는’ 실손보험 청구 전산화가 순차적으로 시행됩니다」(2024.10.25)](https://www.fsc.go.kr/po010101/83255)와 금융위원회가 제공한 복지로 카드뉴스 [「10월 25일부터 실손보험금 청구 전산화」](https://www.bokjiro.go.kr/ssis-tbu/cms/pc/news/promotion/1307392_1118.html)를 기준으로 정리했습니다.

## 청구 전산화, 무엇이 달라졌나

예전에는 실손보험을 청구하려면 병원 창구에서 영수증과 세부내역서를 받아, 사진을 찍어 보험사 앱에 올리거나 팩스로 보내야 했습니다.

청구 전산화가 적용된 병원에서는 실손24에서 병원과 진료 내역을 고르기만 하면, 병원이 다음 서류를 보험회사로 직접 보냅니다.

- 진료비 계산서·영수증
- 진료비 세부산정내역서 (어떤 검사·치료에 얼마가 들었는지 적힌 내역)
- 처방전

금융위원회가 2025년 8월 7일 낸 보도자료 [「금융위, 실손보험 청구 전산화 준비 현황을 유관기관과 심층 점검」](https://fsc.go.kr/po010101/85059)에 실린 소비자 조사(2025년 4월)에서는 응답자의 89%가 기존 방식(보험사 앱, 팩스 등)보다 더 편리하다고 답했습니다.

## 어떤 병원에서 쓸 수 있나

청구 전산화는 두 단계로 넓어졌습니다.

1. **1단계 (2024년 10월 25일~)**: 병원급 의료기관(병상 30개 이상)과 보건소
2. **2단계 (2025년 10월 25일~)**: 동네 의원과 약국 (금융위원회 자료 기준 약 9.6만 곳)

다만 대상이 되었다고 모든 곳이 바로 연결된 것은 아닙니다. 1단계 시작일 기준 참여를 확정한 곳은 4,223곳(병원 733곳, 보건소 3,490곳)으로 참여율 54.7%였고, 2025년 8월 5일 기준으로도 의원·약국 참여율은 약 2.2%에 그쳤습니다. 그래서 **청구 전에 내가 간 병원이 참여했는지 확인하는 것**이 첫 단계입니다.

참여 병원은 실손24의 병원 찾기 기능에서 확인할 수 있고, 금융위원회는 네이버지도·카카오맵에서도 참여 병원을 검색할 수 있게 연계한다고 밝혔습니다.

## 실손24로 청구하는 순서

복지로 카드뉴스에 나온 청구 순서는 다음과 같습니다.

1. 플레이스토어나 앱스토어에서 **실손24** 앱을 설치합니다. (웹페이지로도 가능)
2. 로그인하고 본인인증을 합니다.
3. 내 **보험계약을 조회**합니다.
4. 진료받은 **병원을 선택**합니다.
5. **진료 일자와 내역**을 고릅니다.
6. **청구서**를 작성합니다.
7. 청구 내용을 확인하고 **전송**하면 청구가 끝납니다.

미성년 자녀의 보험금은 가족관계를 전산으로 확인해 청구할 수 있고, 앱 사용이 어려운 부모님은 자녀 등이 대신 청구할 수 있다고 안내되어 있습니다.

## 주의할 점

- **참여하지 않은 병원은 예전 방식으로 청구합니다.** 실손24에서 병원이 보이지 않으면, 병원에서 서류를 받아 가입한 보험회사 앱이나 팩스 등으로 청구해야 합니다.
- **2024년 10월 25일 이전 진료는 전자 전송이 안 됩니다.** 그 전에 받은 진료는 종이 서류가 필요합니다.
- **보험금이 얼마 나오는지는 내 약관이 정합니다.** 청구 전산화는 서류를 보내는 방법이 바뀐 것일 뿐, 보장 범위나 자기부담금은 가입한 상품의 약관을 따릅니다. 금액이 궁금하면 보험회사에 확인하세요.
- **참여 기관은 계속 바뀝니다.** 이 글의 참여 숫자는 금융위원회 발표 당시 기준이므로, 실제 참여 여부는 청구할 때 실손24에서 다시 확인하세요.

## 정리

- 실손보험 청구 전산화는 병원이 영수증·세부내역서·처방전을 보험회사로 전자 전송하는 제도입니다.
- 2024년 10월 25일 병원·보건소, 2025년 10월 25일 의원·약국으로 대상이 넓어졌습니다.
- 실손24 앱에서 보험계약 조회 → 병원 선택 → 진료 내역 선택 → 청구서 작성 → 전송 순서로 청구합니다.
- 참여하지 않은 병원이라면 기존처럼 서류를 받아 보험사에 청구합니다.
